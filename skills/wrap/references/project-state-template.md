# Project state template

Write `PROJECT-STATE.md` in this shape. Keep it short enough to read in two minutes.

```markdown
# Project state: <project name>

- Last updated: <YYYY-MM-DD HH:MM, local time>
- Current goal: <one sentence>
- Status: Not started / In progress / Ready for review / Blocked

## Start here

Read these files in order:

1. PROJECT-STATE.md
2. <brief or source file>
3. <current working file, for example SPEC.md>
```
