# Stakeholder register template

Write `STAKEHOLDER-REGISTER.md` in this shape. Keep it plain. Omit rows that do not apply.

```markdown
# Stakeholder register: <product name>

- Last updated: <YYYY-MM-DD>
- Source: SPEC.md <version>

## Stakeholders

| Stakeholder | Group | How they are affected | How they learn about it | Benefits | Burdens | Owner or representative |
|---|---|---|---|---|---|---|
| <name> | Internal / External, direct / External, indirect | | | | | |

## Notes

- Stakeholders we may be missing:
- Stakeholders to involve before launch:

## Update log

- <YYYY-MM-DD>: <what changed>
```
